# POLY — Oceanic Robotics

Сайт лаборатории океанической робототехники POLY: процедурная робо-медуза Medusa JF-4, интерактивная лаборатория, статистика и мини-игра «Свет в кадре».

## Вкладки

- **Обзор** — главная страница с живой 3D-моделью, статистикой проекта и секцией технологий.
- **Лаборатория** — полный интерактивный симулятор Medusa JF-4: 8 рук, 224 звена, оптика, насос и сифон.
- **Игра** — тренажёр оператора: настройка света и эталонный кадр.

Кнопка **Статистика** в верхней панели открывает окно с онлайном, посещениями и графиком за 14 дней (Firebase Realtime Database).

## Локальный запуск

```text
start-server.bat
```

или

```bash
node server.js
```

Сайт откроется на `http://localhost:8090`. Для телефона в той же Wi-Fi сервер выводит локальный адрес.

Это статический сайт: `index.html`, `lab.html`, `game.html`, папки `css`, `js`, `fonts`, `vendor`.
